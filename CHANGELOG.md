# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

Откат к прошлому состоянию: скопируйте папку проекта в архив перед крупными правками или храните копию `dist\`.

## [0.2.0] — 2026-08-05

### Добавлено

- **Клик по любой карточке в блоке 3 открывает её на весь экран.** Идёт линейный проход по
  текущему отфильтрованному списку (категория × уроки), начиная с нажатой карточки — без
  перемешивания и без повторной вставки (в отличие от обычного урока). Ответ «знаю»/«учить»
  засчитывается по-настоящему (те же счётчики и сердечки, что и в уроке); категория слова при
  этом не пересчитывается — она фиксируется один раз при первом освоении, как и раньше.
  Кнопка «Назад» вверху слева — как в обычном уроке.
- **Массовый выбор карточек.** Кнопка «Выбрать» включает режим выбора — тап по карточке
  отмечает её; появляется панель действий:
  - **«▶ Изучить»** — открывает те же самые линейные ревью, но только по выбранным карточкам.
  - **«Переместить в…»** — принудительно переносит выбранные слова в Легко/Средняя/Сложно
    (слово при этом помечается освоенным, если ещё не было — иначе оно туда не попадёт).
  - **«★ В избранное» / «☆ Убрать из избранного»** — массово, отдельно от переноса по сложности.
  - **«Выбрать всё» / «Снять всё»** — по текущему отфильтрованному списку.
- **Фильтр по урокам** — раскрывающийся список с чекбоксами под строкой категорий, можно выбрать
  один или несколько уроков сразу; работает вместе с категорией (Категория × Уроки), не вместо неё.
- Строки «Блок 3» и «Третий раздел — заготовка» вверху панели убраны для этой вкладки —
  сразу начинаются кнопки категорий.

### Изменено

- `lessonStudyView.ts` обобщён под два режима: `lesson` (как раньше — перемешанная очередь
  с повтором до полного освоения, один урок) и `review` (линейный проход по произвольному
  списку из нескольких уроков сразу — для блока 3). Слово теперь несёт свой номер урока
  само (`StudyCard`), а не берёт один общий на всю сессию.

## [0.1.9] — 2026-08-03

### Добавлено

- **Раскрытие перед переходом к следующей карточке.** При ответе «знаю» / «учить» (кнопкой или свайпом)
  перед тем как показать следующее слово, приложение раскрывает всё, что было скрыто режимом показа
  (🖼/ES/RU), и — если произношение на этой карточке ещё ни разу не звучало (ни кнопкой 🔊, ни
  «Подсказкой») — проигрывает его автоматически.
  - Если звук уже звучал на этой карточке, повторно он не проигрывается — просто раскрываются
    оставшиеся скрытые поля.
  - Если раскрывать нечего и звук уже звучал — переход происходит мгновенно, как раньше.
  - Пауза перед переходом = длительность звука + 0.1с, но не короче 1.5с; если звук не проигрывается
    (уже звучал или файла нет) — ровно 1.5с.
  - Ответ («знаю»/«учить») засчитывается в прогресс сразу по нажатию — раскрытие лишь откладывает
    визуальный переход к следующей карточке, на статистику не влияет.

## [0.1.8] — 2026-08-03

### Добавлено

- **Режим показа полей на карточке.** Три переключателя 🖼 / ES / RU в шапке экрана урока — скрывают
  картинку, испанское слово или перевод. Режим глобальный (один на всё приложение, хранится в
  `localStorage`, ключ `mnemonic-visibility-v1` — модуль `src/section1/visibilityPrefs.ts`) и
  применяется сразу ко всем карточкам всех уроков; можно скрыть от 0 до всех 3 полей одновременно.
- **Тап по видимому полю прячет его, по скрытому — открывает**, но только для текущей карточки:
  на следующей карточке снова действует глобальный режим. Скрытое поле показывается плейсхолдером
  с иконкой 👁 и подписью «Нажми, чтобы показать» — не пустым местом.
- Кнопка 🔊 (озвучка) работает независимо от того, скрыто ли испанское слово — аудирование отдельный навык.

### Изменено

- Клик по картинке и по испанскому слову раньше проигрывал озвучку — теперь это скрывает/показывает
  поле; послушать слово можно только явной кнопкой 🔊.

## [0.1.7] — 2026-08-03

### Исправлено

- Сборка: в `package.json` не хватало `vite-plugin-singlefile` — `npm install` на чистой машине ломал `npm run build`. Версия `package.json` синхронизирована с `CHANGELOG.md`.
- Свайп на экране «Урок завершен» или «Нет слов» уводил карточку за пределы экрана и вешал приложение (карточка не возвращалась, кнопка «Назад» была на ней же). Теперь свайп/кнопки не отвечают, если отвечать не на что.
- Двойной ответ при быстром клике «знаю»/«учить» во время анимации улёта карточки после свайпа — кнопки блокируются на время анимации.
- Ошибка `localStorage.setItem` (приватный режим, переполненная квота, заблокированное хранилище на `file://`) падала необработанной — теперь прогресс просто не переживёт перезагрузку, но текущая сессия продолжает работать.
- Убран двойной инкремент `seenCount` (считался и при показе карточки, и при ответе на неё).
- Удалён неиспользуемый тип ответа `'review'` (кнопка «повторить» была убрана из интерфейса раньше).

### Изменено

- Нормализация испанского слова и имя папки урока (`lesson-01` и т.д.) вынесены в один модуль `src/shared/wordKey.ts` — раньше были скопированы в четырёх местах.
- Прогресс (`section3/progress.ts`) кэшируется в памяти на сессию вместо повторного `JSON.parse` всего `localStorage` на каждый показ и ответ карточки.
- Уроки без слов (2–16) в списке тем помечены «скоро» и неактивны — раньше открывались в тупиковый экран «Нет слов».
- Мнемонические подсказки урока 1 перенесены из захардкоженного словаря `associations.ts` (файл удалён) в поле `hint` соответствующих слов в `words.json` — теперь подсказку для любого урока можно добавить прямо в данных.
- В `words.json` добавлено необязательное поле `asset` — явное имя файла картинки/звука для слов, которые не могут дать корректное имя файла сами (слэш, пробелы): `¡Encantado/a!`, `¿Cómo te llamas?`.
- Картинки без соответствующего слова в `words.json` (местоимения `yo`, `tú`, `él`...) перенесены из `src/assets/cards/` в `src/assets/cards-unused/`, чтобы не раздувать однофайловую офлайн-сборку; удалён обнаруженный битый дубликат `continuar (2).png`.

### Доступность

- Экран изучения закрывается по `Escape`; фокус переходит на кнопку «Назад» при открытии и возвращается на нажатую карточку урока при закрытии.
- Испанский текст помечен `lang="es"` (карточка урока и словарь в разделе 3), чтобы скринридеры не читали его правилами русского языка.
- Свайп карточки переведён с Touch Events на Pointer Events — жест работает мышью и стилусом, а не только пальцем.

### Добавлено

- Запускающий файл переименован в понятное **`Запустить приложение.bat`** (был `открыть-офлайн.bat`).
- Ярлык **`Карточки слов.lnk`** в корне проекта — с иконкой (`public\app-icon.ico`), запускает
  `Запустить приложение.bat`, чтобы не искать `dist\index.html` вручную.
