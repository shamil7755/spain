# Архитектура проекта «Карточки слов» (mnemonic-cards)

Документ описывает, что это за приложение, из чего оно состоит и **за что отвечает каждый файл**.
Версия проекта на момент описания: `0.2.0` (синхронизирована в `package.json` и `CHANGELOG.md`).

---

## 1. Что это такое

Мобильное веб-приложение (одна страница) для изучения **испанских слов по мнемоническим карточкам**
с русским переводом, картинкой-ассоциацией, озвучкой и текстовой подсказкой-мнемоникой.

Ключевые свойства:

- **Полностью офлайн.** Сборка складывает весь код, стили, картинки и mp3 в **один файл** `dist/index.html`
  (~82 МБ, ассеты зашиты как base64). Его можно открыть двойным щелчком без сервера и интернета.
- **Без фреймворков.** Только Vite + TypeScript и ручное создание DOM (`document.createElement`).
  Нет React/Vue, нет роутера, нет стейт-менеджера, нет бэкенда.
- **Без сети и аккаунтов.** Прогресс хранится в `localStorage` браузера (ключ `mnemonic-progress-v1`).
- **Мобильная вёрстка.** Колонка максимум 480px по центру, фиксированное нижнее меню из 4 вкладок,
  свайпы пальцем на карточках, учёт `safe-area-inset`.
- **Тёмная/светлая тема** автоматически по `prefers-color-scheme`.

Содержимое (слова, картинки, звук, мнемоники) — **данные в репозитории**, а не загружаемый контент.
Реально наполнен только **урок 1** (33 глагола на `-ar` + 12 приветствий/фраз); уроки 2–16 — пустые заготовки.

## 2. Как это работает: поток данных

```
index.html
  └── src/main.ts                     точка входа: подключает стили, монтирует приложение
        └── src/mount.ts              весь каркас UI: вкладки, панель, оверлей урока
              ├── src/nav.ts          хранилище активной вкладки (1/2/3/4)
              ├── src/content.ts      заголовок и подсказка для каждой вкладки
              ├── section1/render.ts        вкладка 1: список из 16 уроков
              ├── section3/render.ts        вкладка 3: словарь по категориям
              └── section1/lessonStudyView.ts   экран изучения (оверлей поверх всего)
                     ├── section1/lessons/*     слова урока (JSON, включая подсказку hint)
                     ├── section1/cardImages.ts картинка к слову
                     ├── section1/cardAudio.ts  озвучка слова
                     ├── shared/wordKey.ts      нормализация слова/папки — общая для всех модулей выше
                     └── section3/progress.ts   чтение/запись прогресса в localStorage
```

Сценарий пользователя:

1. Открывается вкладка **1** — список «Урок 1 … Урок 16», справа на каждой карточке счётчик `освоено/всего`.
2. Клик по уроку → `mount.ts:openLesson()` берёт слова урока, **выкидывает уже освоенные**,
   строит экран изучения (`mode: 'lesson'`) и показывает его в полноэкранном оверлее (нижнее меню прячется).
3. На карточке: картинка, испанское слово (клик = скрыть/показать), перевод, кнопка «Подсказка», кнопка 🔊
   (озвучка — отдельно от клика по слову), три сердечка (прогресс по слову) и счётчик `N из M` сверху.
4. Ответ: кнопки **«знаю» / «учить»** или **свайп** (влево = знаю, вправо = учить) — перед переходом к
   следующей карточке раскрывается всё скрытое и при необходимости проигрывается произношение (см. ниже).
5. Слово считается **освоенным после 3 подряд «знаю»**; иначе оно возвращается в очередь через 5–10 карточек.
6. Когда освоены все слова урока — экран «🏁 Урок завершен» с кнопкой «Пройти урок еще раз» (сброс прогресса урока).
7. Вкладка **3** — словарь всех *увиденных* слов, разложенный по категории (Все / Легко / Средняя / Сложно /
   Избранное) и по урокам (фильтр можно комбинировать с категорией). Клик по карточке открывает её на весь
   экран (`mode: 'review'`) и идёт линейно по текущему отфильтрованному списку начиная с неё — без
   перемешивания. Кнопка «Выбрать» включает массовый выбор: можно перенести карточки в другую категорию
   сложности, добавить/убрать из избранного или запустить ревью только по выбранным.

### 3.2 Ядро приложения — `src/`

| Файл | За что отвечает |
|---|---|
| `main.ts` | Точка входа. Импортирует `styles/main.css`, находит `#app`, вызывает `mountApp(root)`, пишет в `<html data-lesson-word-sets="16">` количество наборов слов (диагностический атрибут). |
| `mount.ts` | **Главный композитор UI.** Создаёт `<main>` с панелью (заголовок, подсказка, тело — скрыты для вкладки 3, там сразу начинаются кнопки категорий), нижнюю навигацию из 4 табов с корректной ARIA (`role=tablist/tab/tabpanel`), оверлей карточки. Содержит `syncUi()` (перерисовка содержимого вкладки), общий `showStudyOverlay(view)` (показ полноэкранного оверлея — фокус, скрытие меню, блокировка скролла через класс `lesson-open`), `openLesson(lessonNumber)` (урок, `mode: 'lesson'`, слова урока с довешенным `lessonNumber`) и `openReview(items, startIndex)` (карточка из блока 3, `mode: 'review'`, список может содержать слова из разных уроков) — обе строят `StudyCard[]` и передают в `createLessonStudyView`, `closeLesson()` закрывает в обоих случаях. Колбэки `onWordSeen`/`onWordAction` теперь принимают `lessonNumber` явным параметром (не из замыкания) — нужно для смешанных по урокам списков ревью. |
| `nav.ts` | Тип `TabId = '1'|'2'|'3'|'4'`, список `TAB_IDS` и крошечное **хранилище состояния** `createTabStore` (get / set / subscribe) — паттерн «наблюдатель» на `Set` слушателей. |
| `content.ts` | Тексты панели: заголовок и подсказка для каждой вкладки. Для вкладки 1 берёт их из `section1/settings.json`, для 2/3/4 — заглушки («Блок 2» и т.д.). |

### 3.2а Общий модуль — `src/shared/`

| Файл | За что отвечает |
|---|---|
| `wordKey.ts` | Единая **нормализация испанского слова** (`normalizeWord`) и **имя папки урока** (`lessonFolderKey`, `1` → `lesson-01`) — раньше были скопированы в `lessonStudyView.ts`, `cardImages.ts`, `cardAudio.ts` и `progress.ts` по отдельности; расхождение одной копии от других незаметно ломало поиск картинки/звука или чтение прогресса. Также `lessonNumberFromId` — номер урока из id темы (`lesson-1` → `1`). |

### 3.3 Раздел 1 — уроки и изучение, `src/section1/`

| Файл | За что отвечает |
|---|---|
| `settings.json` | Настройки раздела: заголовок панели («Темы»), подсказка, количество уроков (`count: 16`) и шаблон названия (`"Урок {n}"`). |
| `types.ts` | Типы этих настроек (`Section1Settings`, `Section1Topic`). |
| `index.ts` | Публичное API раздела: `getSection1Panel()` (тексты панели), `getSection1Topics()` (генерирует 16 тем `lesson-1 … lesson-16` из настроек), реэкспорт слов и типов уроков. |
| `render.ts` | **Список уроков** на вкладке 1: кнопка-карточка на урок, справа бейдж `освоено/всего` (данные приходят колбэком `getLessonProgress`), клик → `onLessonSelect(номер)`. Номер урока берётся через `lessonNumberFromId` из `shared/wordKey.ts`. Уроки с `total === 0` (пока без слов) рисуются неактивными, с пометкой «скоро», и не открываются по клику — раньше вели в тупиковый экран «Нет слов». |
| `lessonStudyView.ts` | **Самый большой и главный модуль — экран изучения/просмотра карточки, два режима.** Принимает `words: StudyCard[]` — `WordPair` с обязательным собственным `lessonNumber` на каждом слове (не один общий на сессию), плюс `mode?: 'lesson' \| 'review'` (по умолчанию `'lesson'`) и `startIndex?` (с какой позиции начать — для клика по конкретной карточке в блоке 3). Тексты финального/пустого экрана и подпись кнопки перезапуска настраиваются опциями (`completedTitle`/`completedSubtitle`/`restartLabel`/`emptyTitle`/`emptySubtitle`), чтобы `mount.ts` мог задать разные формулировки для урока и для ревью. Отвечает за: <br>• построение DOM карточки (картинка, слово, перевод, сердечки, подсказка, кнопка озвучки, кнопки ответа);<br>• **очередь показа** `timeline` — в режиме `lesson` перемешанные индексы слов, `ensurePlayableQueue()` пропускает освоенные и дозаполняет очередь, `appendRandomReview()` возвращает неотвеченное слово на 5–10 позиций вперёд; в режиме `review` — индексы **по порядку, без перемешивания**, `ensurePlayableQueue()` и повторная вставка отключены (`isReview` guard), любой ответ просто двигает курсор на 1 дальше;<br>• **завершение сессии** (`isSessionComplete()`) — в `lesson` это «набрали `startMastered + masteredWordKeys.size >= totalInLesson`», в `review` — «дошли до конца списка» (`cursor >= timeline.length`);<br>• **свайп-жесты на Pointer Events** (`pointerdown/move/up/cancel` — работают и мышью, и стилусом, не только пальцем): порог решения 12px, порог срабатывания 70px, поворот и прозрачность карточки, цветная подложка «знаю»/«учить» через CSS-переменные `--swipe-know` / `--swipe-learn`, анимация улёта 160мс. `hasCurrentWord()` не даёт запустить эту анимацию, когда отвечать не на чему (финальный/пустой экран) — раньше карточка в этом случае улетала за экран и не возвращалась;<br>• **финальный экран** и кнопка перезапуска (создаётся один раз, а не на каждый рендер);<br>• пустое состояние (нет слов урока / пустой список ревью);<br>• доступность: фокусируемый корень (`tabIndex=-1`), `lang="es"`/`lang="ru"` на слове в зависимости от того, что показано;<br>• **режим показа полей** — три переключателя 🖼/ES/RU в шапке (глобальный, из `visibilityPrefs.ts`) плюс `cardOverride` — ручной тап по полю переопределяет режим только для текущей карточки, сбрасывается на следующей (`isFieldVisible()`, `toggleCardField()`, `renderEs()`/`renderRu()`/`renderImage()`). Клик по картинке/ES/RU скрывает/показывает поле, а не проигрывает звук — озвучка только через кнопку 🔊, она работает независимо от видимости слова;<br>• **раскрытие перед переходом к следующей карточке** (`revealBeforeAdvancing()`) — при ответе «знаю»/«учить» (кнопкой или свайпом, в обоих режимах) ответ засчитывается сразу через `onWordAction(w.lessonNumber, es, action)`, но сама смена карточки откладывается: раскрывается всё, что было скрыто режимом показа, и если звук ещё не звучал на этой карточке (`audioPlayedThisCard`) — проигрывается автоматически. Пауза = длительность звука + 0.1с (не короче 1.5с) или ровно 1.5с, если звук не проигрывается повторно/файла нет; если раскрывать нечего и звук уже звучал — переход мгновенный. На время паузы `swipeAnimating` держит весь ввод заблокированным (кнопки ответа, 🔊, «Подсказка», новый свайп) и сбрасывается только внутри `nextCard()`. |
| `visibilityPrefs.ts` | Глобальный режим показа полей карточки — `localStorage`, ключ `mnemonic-visibility-v1`, три булевых флага `{image, es, ru}` (по умолчанию все `true`). `getVisibilityPrefs()`, `toggleGlobalFieldVisible(field)`. Один режим на всё приложение, в отличие от прогресса (`progress.ts`) это настройка экрана, а не учебные данные. |
| `flattenLessonWords.ts` | Превращает урок с группами в плоский массив пар слов (порядок как в JSON). |
| `cardImages.ts` | **Поиск картинки к слову.** `import.meta.glob` собирает все файлы `assets/cards/**/*.{png,jpg,jpeg,webp}` в два индекса: по паре «папка урока + слово» и по одному слову (legacy-путь). `getCardImageSrc(lesson, es, asset?)` — сначала картинка из папки `lesson-XX`, потом fallback на плоскую; если у слова в данных задано поле `asset`, имя файла ищется по нему, а не по `es`. |
| `cardAudio.ts` | То же самое для звука: индексирует `assets/audio/**/*.{mp3,wav,ogg,m4a,aac,webm}`, `getCardAudioSrc(lesson, es, asset?)` ищет файл, `playCardAudio()` проигрывает через **один переиспользуемый** `Audio`-элемент (перебивая предыдущий звук) и возвращает сам элемент (или `null`, если файла нет) — нужно `lessonStudyView.ts`, чтобы подписаться на `ended`/`error` и точно рассчитать паузу перед следующей карточкой. |
| `lessons/types.ts` | Формат данных урока: `WordPair {es, ru, hint?, asset?}`, `WordGroup {label, entries}`, `LessonWordsFile {lessonNumber, groups}`. Поле `asset` — явное имя файла картинки/звука для слов, из которых нельзя вывести корректное имя файла (слэш, пробелы). |
| `lessons/registry.ts` | **Реестр уроков**: статически импортирует все 16 `words.json` (важно — статический импорт нужен, чтобы данные попали в офлайн-бандл), отдаёт `ALL_LESSON_WORDS` и `getLessonWords(n)` с проверкой границ 1…16. |
| `lessons/index.ts` | Реэкспорт типов и реестра. |
| `lessons/lesson-01/words.json` | Данные урока 1: группа «Глаголы на -ar» (33 слова, у каждого есть мнемоническая подсказка в поле `hint`) и «Приветствия и фразы» (12 фраз; у двух фраз со слэшем/пробелами задано поле `asset`). |
| `lessons/lesson-02 … lesson-16/words.json` | Пустые заготовки: `{"lessonNumber": N, "groups": []}`. |

### 3.4 Раздел 3 — прогресс и словарь, `src/section3/`

| Файл | За что отвечает |
|---|---|
| `progress.ts` | **Вся логика прогресса и его хранение.** Ключ `localStorage`: `mnemonic-progress-v1`, ключ слова: `"<номер урока>:<нормализованное слово>"`. Разобранное состояние держится в модульном кэше в памяти (`cache`) — `localStorage` парсится один раз за сессию, а не на каждый показ/ответ карточки; запись идёт насквозь (`saveState` обновляет и кэш, и `localStorage`, `try/catch` — квота/приватный режим/`file://` не роняют приложение). На каждое слово хранится: `seen`, `seenCount`, `knowCount`, `learnCount`, `consecutiveKnow`, `mastered`, `masteryCategory`, `wrongBeforeMastery`, `isFavorite`, последние 12 `attempts`.<br>Функции: `markWordSeen()` (показ карточки, инкрементит `seenCount`), `recordWordAttempt()` (ответ `'know'`/`'learn'`; **3 подряд «знаю» → `mastered = true`**, категория сложности по числу ошибок до освоения: 0–1 «учить» = легко, 2–3 = средне, 4+ = сложно), `isWordMastered()`, `getLessonMasteredCount()` (для бейджей в списке уроков), `getCategoryWords()` (выборка для вкладки 3, включает `hint` слова — нужен, чтобы подсказка была доступна и при открытии карточки из блока 3), `toggleFavoriteByKey()` / `setFavoriteForKeys()` (массово), `moveWordsToCategory(keys, category)` (ручной перенос между Легко/Средняя/Сложно — принудительно ставит `mastered = true`, иначе слово не попадёт во вкладку категории), `resetLessonProgress()` (удаляет все ключи с префиксом урока). |
| `render.ts` | **Вкладка 3 — словарь.** Верхний ряд категорий: «Все слова / Легко / Средняя / Сложно / ★ Избранное». Под ним — раскрывающийся чекбокс-список **фильтра по урокам** (`<details>`, только уроки, где реально есть слова) и кнопка **«Выбрать»**; оба фильтра (категория × уроки) действуют одновременно (`currentItems()`). Заголовок и подсказка панели для этой вкладки скрыты в `mount.ts` — сразу начинается ряд категорий.<br>Каждая карточка (`role=button`, кликабельна целиком) — миниатюра, испанский, перевод, номер урока, кнопки 🔊 и ☆/★ (обе гасят всплытие клика на `.section3-word-actions`, чтобы не задеть карточку). Клик по карточке **вне режима выбора** → `onOpenReview(items, index)` — открывает её на весь экран, начиная с этой позиции в текущем отфильтрованном списке (обработчик приходит из `mount.ts:openReview`). Показываются **только слова, которые уже показывались** в уроке.<br>**Режим выбора** («Выбрать» → «Готово»): клик по карточке отмечает её (чекбокс слева), появляется панель массовых действий — «Выбрать всё/Снять всё», «▶ Изучить» (ревью только по выбранным), «Переместить в…» (`moveWordsToCategory`), «★ В избранное»/«☆ Убрать» (`setFavoriteForKeys`), «Отмена». Смена категории или фильтра по урокам сбрасывает выбор. Оба `<details>` (фильтр уроков и меню переноса) закрываются сами при клике вне себя — слушатель на `document` снимает сам себя, когда `section3-root` уходит из DOM (иначе накапливался бы при каждом возврате на вкладку). |

### 3.5 Стили — `src/styles/`

### 3.6 Ассеты — `src/assets/`

| Путь | За что отвечает |
|---|---|
| `assets/cards/lesson-01 … lesson-16/` | Картинки-ассоциации. Имя файла = испанское слово в нижнем регистре (`tomar.png`, `hablar.png`), либо значение поля `asset` из `words.json`. Поддержка `.png .jpg .jpeg .webp`. Реально заполнена только `lesson-01`; остальные папки пустые. Эта папка попадает в бандл **целиком** через `import.meta.glob({eager: true})` — сюда должны лежать только файлы, которым реально соответствует слово. |
| `assets/cards-unused/lesson-01/` | Картинки местоимений (`yo`, `tú`, `él`, `nosotros`…), которым пока не соответствует ни одно слово в `words.json`. ## 4. Правила именования, о которых легко забыть

- **Нормализация слова** — один общий модуль `src/shared/wordKey.ts` (`normalizeWord`), которым пользуются
  `lessonStudyView.ts`, `cardImages.ts`, `cardAudio.ts` и `progress.ts`:
  нижний регистр → `NFD` → снятие диакритики → срез начальных `¡ ¿ ! ?` → срез конечных `! ? . , …` → `trim`.
  Значит `¡Hola!` ищет файл `hola.png` / `hola.mp3`. Если слово не даёт корректное имя файла
  (слэш, пробелы), кладите явное имя в поле `asset` — оно нормализуется вместо `es`.
- **Папка урока** в ассетах всегда с ведущим нулём: `lesson-01`, но в данных `lessonNumber: 1`.
  Преобразование — `lessonFolderKey()` в том же общем модуле.
- **Свайп:** влево = «знаю», вправо = «учить». Работает через Pointer Events — мышью, стилусом и пальцем одинаково.
- **Освоено = 3 «знаю» подряд.** Любой ответ «учить» обнуляет счётчик сердечек и увеличивает `wrongBeforeMastery`.

## 5. Как добавить контент

1. **Слова:** открыть `src/section1/lessons/lesson-XX/words.json`, добавить группы и пары `{"es": "...", "ru": "..."}`.
   Мнемоническая подсказка — сразу в этом же объекте, поле `"hint"`.
   Если слово содержит слэш или пробелы (не даёт нормальное имя файла) — добавьте `"asset": "имя-файла"`.
2. **Картинку:** положить `src/assets/cards/lesson-XX/<слово или asset>.png` (только для слов, которые реально есть в `words.json` —
   лишние файлы раздувают однофайловую сборку, складывайте их в `assets/cards-unused/` до появления слова).
3. **Звук:** положить `src/assets/audio/lesson-XX/<слово или asset>.mp3`.
4. Пересобрать: `npm run build` → открыть `dist/index.html` (или `открыть-офлайн.bat`).

Новые файлы подхватываются автоматически: `import.meta.glob` пересканирует папки при сборке,
регистр в имени файла не важен, а вот **расширение должно быть из поддерживаемого списка**.

## 6. Что не доделано / на что обратить внимание

Пункты ниже уже разобраны и исправлены на 2026-08-03 (см. `CHANGELOG.md` 0.1.7–0.1.8): сборка без
`vite-plugin-singlefile` в зависимостях, зависание на свайпе на пустом/финальном экране, двойной ответ
при свайпе, необработанные ошибки `localStorage`, четыре копии нормализации слова, полный `JSON.parse`
прогресса на каждое обращение, двойной инкремент `seenCount`, мёртвый тип `'review'`, несовпадение
`lesson-1` / `lesson-01`, открытие пустых уроков в тупик, отсутствие способа задать имя ассета для фраз
со слэшем/пробелами, мнемоники в коде вместо данных, отсутствие Escape/фокуса/`lang`, свайп только на Touch Events.

Актуальные открытые вопросы:

- **Вкладки 2 и 4 — пустые заглушки** («Карточки появятся здесь»); тексты живут в `content.ts`.
- **Уроки 2–16 пустые** — в списке уроков помечены «скоро» и неактивны, наполнить их словами ещё предстоит.
- **Размер офлайн-сборки:** `dist/index.html` уже ~82 МБ из-за base64-ассетов (несжатые PNG по 1–2.5 МБ штука).
  С добавлением звука и картинок для остальных 15 уроков файл станет неподъёмным для одного HTML — стоит
  сначала сжать существующие картинки (webp, разумный размер), а при дальнейшем росте — отказаться
  от `vite-plugin-singlefile` в пользу обычной сборки с отдельной папкой ассетов (или PWA).
- **Прогресс только в `localStorage`** текущего браузера: очистка данных сайта или открытие
  свежесобранного HTML из другой папки (`file://` другой путь = другое origin-хранилище) обнуляет прогресс.
- **Освоенное слово исчезает из очереди навсегда** (кроме полного сброса урока целиком) — интервального
  повторения после освоения нет; накопленная статистика (`attempts`, `masteryCategory`) сейчас никуда не используется.
- **Git в проекте отключён** (см. CHANGELOG 0.1.1), версионирование — копированием папки, история — в `CHANGELOG.md`.
