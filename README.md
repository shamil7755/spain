# Карточки слов (мнемоника)

Мобильный веб-интерфейс для изучения слов с нижним меню из четырёх блоков.

**Папка проекта:** `D:\mnemonic-cards`

## Просмотр офлайн (без сервера, без интернета)

Самый простой способ — дважды кликнуть по ярлыку **`Карточки слов.lnk`** в корне проекта
(у него своя иконка-карточка). Ярлык запускает **`Запустить приложение.bat`**, который
открывает `dist\index.html` в браузере по умолчанию.

Можно и без ярлыка — сразу открыть готовый HTML двойным щелчком:

- файл `dist\index.html`
- рядом с ним должен лежать `dist\favicon.svg` (копируется сборкой автоматически)

Если вы меняли код в `src\`, пересоберите:

```bash
cd D:\mnemonic-cards
npm run build
```

## Разработка (с автообновлением)

```bash
cd D:\mnemonic-cards
npm install
npm run dev
```

## Раздел 1 (темы / уроки)

Настройки лежат в **`src\section1\`**: заголовок, подсказка и список тем задаются в **`settings.json`**. После правок выполните `npm run build` и снова откройте офлайн-страницу.

**Слова по урокам:** папки **`src\section1\lessons\lesson-01`** … **`lesson-16`**, в каждой файл **`words.json`** (пары `es` / `ru`, блоки `groups` с полем `label`). Редактируйте нужный урок и пересоберите проект.

**Картинки к словам (по урокам):** положите файл в папку урока:

- `src\assets\cards\lesson-01\<испанское_слово>.png`
- `src\assets\cards\lesson-02\<испанское_слово>.jpg`
- ...

Имя файла без расширения должно совпадать со словом в данных урока (например `tomar.png` для слова `tomar`).  
Поддерживаются `.png`, `.jpg`, `.jpeg`, `.webp`.

> Для совместимости пока работает и старый путь `src\assets\cards\<слово>.*`, но приоритет у картинки из папки конкретного урока.
