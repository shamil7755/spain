# Как редактировать карточки и создавать новые

Инструкция для самостоятельного наполнения уроков — без правок кода, только данные (JSON) и файлы-ассеты (картинки, звук).

---

## 1. Где живут слова урока

Каждый урок — папка `src\section1\lessons\lesson-XX\` (например `lesson-02`), внутри один файл — **`words.json`**. Открывать и редактировать можно в любом текстовом редакторе (Блокнот, VS Code).

Формат (посмотри для примера `lesson-01\words.json`):

```json
{
  "lessonNumber": 2,
  "groups": [
    {
      "label": "Еда",
      "entries": [
        { "es": "pan", "ru": "хлеб" },
        { "es": "agua", "ru": "вода", "hint": "Твоя подсказка-ассоциация тут" }
      ]
    },
    {
      "label": "Ещё одна тема, если хочешь",
      "entries": [
        { "es": "leche", "ru": "молоко" }
      ]
    }
  ]
}
```

- `groups` — это тематические блоки внутри урока (можно один, можно несколько — `label` просто подпись, на прохождение не влияет, все слова урока идут в одну общую очередь).
- Каждое слово — `{ "es": "...", "ru": "..." }`. Через запятую добавляй сколько угодно пар.
- **Важно:** после каждой пары кроме последней в списке должна стоять запятая; после последней — нет. Если собьёшься с запятыми, JSON не соберётся (сборка выдаст ошибку — не страшно, просто поправь).

**Проверить, что JSON не сломан**, можно перед сборкой, если есть Node:
```
node -e "JSON.parse(require('fs').readFileSync('src/section1/lessons/lesson-02/words.json','utf8')); console.log('ок')"
```
Или просто попробовать `npm run build` — если JSON битый, `tsc`/vite сразу укажут файл и строку.

---

## 2. Куда писать подсказку (мнемонику)

Прямо в той же паре, поле `"hint"`:

```json
{ "es": "agua", "ru": "вода", "hint": "Представь агу-агу младенца, который пускает пузыри в воде." }
```

Необязательное поле — если его нет, кнопка «Подсказка» на карточке просто станет неактивной.

---

## 3. Куда класть картинку

Файл кладёшь в папку урока в ассетах:

```
src\assets\cards\lesson-02\<слово>.png
```

Имя файла (без расширения) должно **совпадать со словом** после нормализации: нижний регистр, без ударений/тильд, без крайних `¡ ¿ ! ? . , …` по краям. Практически — просто называй файл строчными буквами так же, как слово в `es`, без начальных/конечных знаков препинания.

Примеры:
- `es: "agua"` → файл `agua.png`
- `es: "¡Hola!"` → файл `hola.png` (восклицательные знаки в имени файла не нужны)
- `es: "Café"` → файл `cafe.png` (без диакритики)

Поддерживаемые расширения: `.png`, `.jpg`, `.jpeg`, `.webp`.

---

## 4. Куда класть аудио

Аналогично, но в audio-папку урока:

```
src\assets\audio\lesson-02\<слово>.mp3
```

Те же правила именования, что и для картинок. Поддерживаются `.mp3`, `.wav`, `.ogg`, `.m4a`, `.aac`, `.webm`.

---

## 5. Как это «распознаётся»

Никакой ручной привязки делать не нужно — при сборке (`npm run build`) код сам сканирует папки `assets\cards\**` и `assets\audio\**` и составляет индекс по имени файла. Когда на экране показывается слово, оно ищет файл с точно таким же нормализованным именем **в папке этого же урока**. Совпало имя — картинка/звук подключились автоматически.

**Если слово содержит слэш или пробелы** (например `"¡Encantado/a!"` или `"¿Cómo te llamas?"`) — из него нельзя получить корректное имя файла. Для таких случаев добавь третье поле `"asset"` с ручным именем файла, а сам файл назови так же:

```json
{ "es": "¿Cómo te llamas?", "ru": "Как тебя зовут?", "asset": "como-te-llamas" }
```
→ файл `src\assets\cards\lesson-02\como-te-llamas.png` и `src\assets\audio\lesson-02\como-te-llamas.mp3`.

Картинка и звук необязательны — если файла нет, приложение просто не покажет картинку/не даст кнопку озвучки для этого слова, ошибки не будет.

---

## 6. Раздел 3 (общий список слов) — важный нюанс

Раздел 3 показывает **не все слова из JSON**, а только те, что пользователь уже **хотя бы раз увидел** на экране изучения урока. То есть: добавил слова в `words.json` → собрал проект → открыл этот урок в разделе 1 и прошёл его (или хотя бы полистал карточки) → только после этого слова появятся в разделе 3, с категорией по сложности («Легко»/«Средняя»/«Сложно») в зависимости от того, как ты на них отвечал.

Так что если после наполнения урока в разделе 3 пусто — это ожидаемо, просто открой урок и посмотри карточки.

---

## 7. Что происходит с пустыми уроками автоматически

Пока в `words.json` `"groups": []` (пусто), урок в списке помечен «скоро» и неактивен. Как только добавишь хотя бы одно слово в `entries` любой группы — при следующей сборке урок сам станет кликабельным, а счётчик в разделе 1 начнёт показывать `0/N` вместо «скоро».

---

## 8. Итоговый чек-лист на один урок

1. Открой `src\section1\lessons\lesson-XX\words.json`, впиши слова (`es`/`ru`, по желанию `hint`, при спецсимволах — `asset`).
2. Положи картинки в `src\assets\cards\lesson-XX\` с совпадающими именами.
3. Положи звук в `src\assets\audio\lesson-XX\` с совпадающими именами.
4. Пересобери:
   ```
   cd D:\mnemonic-cards
   npm run build
   ```
5. Открой ярлык «Карточки слов» (или `dist\index.html`) — заново проверь урок.

Если что-то не подключилось — почти всегда причина одна: имя файла не совпало со словом после нормализации (лишняя буква, заглавные там, где не важно, но лучше не рисковать — используй строчные, или забытое ударение/тильда в имени файла при наличии её в слове — их как раз нужно убирать).
